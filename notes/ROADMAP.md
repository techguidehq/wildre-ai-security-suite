# Roadmap

## Included MVP
- CLI: log summary, IOC extraction, raw-file SHA-256, YARA draft
- Unit tests and synthetic fixtures
- Optional MCP server with four tools
- Reverse-engineering, malware-triage, binary-analysis skills
- Ghidra guide and analyst notes pack
- Kenya/Africa mobile-money safety starter
- Claude Code, Cursor, generic agent templates

## Next
1. CI across supported Python versions and linting.
2. JSON/CSV log schemas and richer IOC formats.
3. Markdown report generator for analyst-confirmed findings.
4. MCP integration tests against selected SDK versions.
5. Demo screenshots from synthetic examples.
6. Release signing, dependency review, secret scanning.
7. More localized learning content with current source citations.

## Non-goals
Unauthorized exploitation, credential theft, stealth/evasion, arbitrary shell execution, auto-visiting URLs, and uploading private artifacts by default.
